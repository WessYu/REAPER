# SARIF validation schema

`sarif-2.1.0.json` is the OASIS SARIF 2.1.0 JSON schema retrieved from:

https://github.com/oasis-tcs/sarif-spec/blob/main/sarif-2.1/schema/sarif-schema-2.1.0.json

The schema is maintained by OASIS; consult the upstream repository for applicable notices and license terms. It is vendored for offline test reproducibility, not generated from REAPER's output.
